# Contributing

## Report a problem or suggest an improvement

Open a GitHub issue and include the project name, what you were trying to do, and what happened. For a bug, include the steps to reproduce it, your operating system, and relevant software versions. Use a small shareable example when possible.

## Make a change

1. Fork the repository or create a branch if you have access.
2. Keep changes inside the relevant project folder.
3. Follow that project's setup and verification instructions.
4. Update its README when usage or requirements change.
5. Open a pull request describing the change and how you checked it.

## Add a project

Use `projects/<project-name>/` and include a README based on the template in `templates/project/README.md`. List the new project in the main README. Preserve existing source structure, dependency lockfiles, attribution, and license notices.

## Licensing

Submit original contributions under this repository's MIT license unless the target project specifies another license. Only contribute material you have permission to share, and identify any third-party license terms.
